# memory-test
Приложение на Python для оценки способности пользователя запоминать числа

Описание:
Программа показывает пользователю случайную последовательность цифр на 3 секунды. 
После этого последовательность скрывается, и пользователю необходимо ввести её по памяти.

Возможности программы:

- Прохождение теста на запоминание чисел
- Постепенное увеличение длины последовательности после правильного ответа
- Учёт правильных ответов и ошибок
- Завершение тестирования после трёх ошибок
- Просмотр правил тестирования
- Просмотр результатов прохождения
- Информация о программе
- Изменение размера главного окна

Запуск программы:

1. Установить Python 3.
2. Скачать или клонировать репозиторий.
3. Открыть папку проекта.
4. Запустить команду: python main.py

Дополнительные библиотеки устанавливать не требуется, поскольку программа использует стандартную библиотеку Tkinter Python.
