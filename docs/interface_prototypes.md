Прототипы пользовательского интерфейса

1. Главное меню

Главное меню является начальным экраном приложения.

На экране располагаются:
  Название приложения «Тест на память».
  Кнопка «Начать тестирование».
  Кнопка «Правила тестирования».
  Кнопка «О программе».

В верхней части окна находится меню с разделами «Файл», «Тестирование» и «Справка».

2. Экран тестирования

На экране тестирования отображаются:
  Название текущего режима.
  Текущий уровень и количество ошибок.
  Последовательность цифр для запоминания.
  Поле для ввода ответа.
  Кнопка «Проверить ответ».
  Кнопка перехода к следующему раунду.
  Кнопка возврата в главное меню.

Последовательность цифр показывается в течение трёх секунд, после чего скрывается.

3. Окно правил тестирования

В окне отображаются инструкции по прохождению теста:
  Необходимо запомнить показанную последовательность цифр.
  На запоминание даётся три секунды.
  После скрытия последовательности нужно ввести ответ.
  За правильный ответ длина последовательности увеличивается на одну цифру.

После трёх ошибок тест завершается.

4. Экран результатов

После завершения тестирования пользователь может увидеть:
  Количество правильных ответов.
  Количество ошибок.
  Общее количество попыток.
  Точность ответов.
  Максимальную длину запомненной последовательности.
  Итоговую характеристику результата.

5. Окно «О программе»

В окне отображается название приложения и краткая информация о его назначении.

Общие особенности интерфейса:
  Интерфейс приложения выполнен в светлой цветовой гамме. 
  Для оформления используются светлый фон, синие кнопки и читаемые надписи.

  Главное окно можно изменять по размеру. 
  Для удобства пользователя предусмотрена навигация через кнопки и верхнее меню.
